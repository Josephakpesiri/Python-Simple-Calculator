# Python-Simple-Calculator
Build a simple Python calculator that:

1️⃣ Asks the user for two numbers.

2️⃣ Stores the numbers in variables.

3️⃣ Calculates and displays:

* Addition
* Subtraction
* Multiplication
* Division

4️⃣ Use f-strings to display your results clearly.

💡 EXPECTED RESULT

Your program should produce something similar to:

Enter first number: 20
Enter second number: 5

Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4.0
